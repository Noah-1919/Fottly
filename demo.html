Demo — media-mvp

This is how a client's website would see its images served through your API. Each card is a real request to your server.

Configuration

Requires docker compose up to be running and the file to already exist in the bucket (uploaded earlier via the MinIO console). The quick examples show: original, 300x300 crop, fit without cropping, background removed, and watermark if you fill in that field.

Custom transformation

Fill in whichever fields you want to combine and click the button — a new card is added below with exactly that URL.
